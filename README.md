### 🏕️ Sistema Web de Gestión de Scouts — Proyecto académico colaborativo
Participé como desarrollador Front End de dos pantallas principales: Un Dashboard Inteligente y un Formulario Interactivo.

Trabajé con **Vue, Node.js, HTML, CSS y JavaScript**, donde conecté la vista gráfica de el frontend en ambas pantallas configurando el enrutamiento con el backend existente para su funcionamiento e interacción con el usuario, validando la integración de los datos en el sistema mediante el uso de consultas complejas en base de datos **SQL** con el sistema de gestión de base de datos **MariaDB** para el uso y la carga de los datos hacia el frontend, utilizando la API Rest como puente entre el backend y el frontend del proyecto; hice uso de la conexión entre el gestor de bases de datos con el backend existente del proyecto para poder enviar y obtener los datos desde ambas pantallas en el frontend hacia el backend del proyecto, de esta manera pudiendo obtener los datos de la base de datos contectandola al frontend mediante la API Rest del proyecto. De esta manera logré testear, depurar y validar ambas pantalla para el uso los datos y para su disponibilidad con el usuario, logrando poder ejecutar operaciones CRUD de forma dinámica desde la interfáz del frontend del proyecto, solucionando de esta manera los problemas de comunicación entre ambas capas.
